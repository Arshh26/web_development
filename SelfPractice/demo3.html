Conditional Statements

Conditional Statements is used to make decision in a program, They execute different blocks based on the wheather a condition is true or false

Those Conditional Satements are:
    if statement
    if...else statement
    else ladder statement
    Nested if statement
    switch statement
    Ternary statement

1.if statement

if statement executes a block only if a condition is true

2.if...else statement

if statement executes a block only if a condition is true, else block executes if only if the condition if false

3.else ladder statement

it is used when there is a multiple else block

4.Nested if statement

if statement inside a another if statement is know as nested if

5.Switch statement

switch statement used when one variable needs to be compared with multiple possible values

6.Ternary statement

it a shorter version of if...else block, it is called ternary Operator because it works on 3(three) operands, those are

    Condition
    Expression if the condition is true
    Expression if the condition is false
